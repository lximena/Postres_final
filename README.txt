PROYECTO POSTRES

Estructura de la carpeta src/:

src/
  Componentes/
    Formularios/   (Campos, Boton)
    Hook/          (useTarjetas, useFormulario)
    Home/          (Efecto)
    Orquestador/   (Tarjeta, Formulario)
    pages/         (App, h, Tar, FormularioPage)
    Styles/        (main.css, Tarjeta.css, Formulario.css, h.css)
    Tarjetas/      (Titulo, Descripcion, Imagen, Ingredientes, Boton)
  img/
  data.json
  main.jsx

Para ejecutar el proyecto:
1. Abrir la carpeta en VS Code.
2. Abrir la terminal.
3. Ejecutar: npm install
4. Ejecutar: npm run dev
